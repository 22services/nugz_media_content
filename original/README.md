# original/

Holds the untouched source `video_01_brut_nugz.MOV` (iPhone 15 Pro Max, HEVC 10-bit HDR HLG,
1080×1920, 30 fps, 8:20.9, 428,290,068 bytes).

- The file itself is **not in git** (too large for GitHub, and it is a master that must stay
  byte-identical). Its home is the GitHub Release `video-brut-nugz`.
- Get it with `scripts/fetch_original.sh`, which downloads it, checks the SHA-256 and sets
  it read-only:
  `3120823ece49226f823d5b24590b418b4e4573afc767142c064a38885b0fe125`
- Never edit, rename, transcode or overwrite it. All derived files go to `exports/`.
- ⚠️ The file contains the GPS location of the recording, and the Release is public.
